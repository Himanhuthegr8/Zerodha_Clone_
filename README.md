🧭 Overview
This project is a frontend clone of Zerodha, one of India's leading stock trading platforms. The goal is to replicate its landing page and dashboard UI to better understand layout structuring, responsive design, and frontend development workflows.

✨ Features
Responsive landing page

Smooth navigation menus

Simulated login and sign-up interfaces

Dashboard-style layout

Clean and modular codebase

🛠️ Tech Stack
HTML5 , React – Markup structure 

CSS3 – Styling and responsive layout (Flexbox/Grid)

JavaScript (ES6+) – Interactivity and DOM manipulation
